### 2. Extensión del comando `setup`
**Archivo modificado**: `src/Commands/SetupCommand.php`

**Nuevas opciones agregadas**:
- `--skip-theme`: Saltar activación de tema
- `--skip-plugins`: Saltar activación de plugins
- `--theme=THEME`: Tema a activar (no interactivo)
- `--plugins=PLUGINS`: Plugins a activar separados por coma (no interactivo)

**Nuevos métodos implementados**:
- `setupTheme()`: Gestiona activación de temas
  - Lista temas disponibles en `web/app/themes`
  - Permite selección interactiva (nombre o número)
  - Activa tema usando WP-CLI
  - Soporta flag `--theme` para modo no interactivo

- `setupPlugins()`: Gestiona activación de plugins
  - Lista plugins disponibles en `web/app/plugins`
  - Permite selección múltiple separada por comas
  - Activa cada plugin usando WP-CLI
  - Soporta flag `--plugins` para modo no interactivo

**Flujo de setup mejorado**:
1. Instalar WordPress (si no existe)
2. Configurar Acorn (si está instalado)
3. **NUEVO**: Activar tema (interactivo o flag)
4. **NUEVO**: Activar plugins (interactivo o flag)

### 3. Extensión del comando `info`
**Archivo modificado**: `src/Commands/InfoCommand.php`

**Nuevos métodos implementados**:
- `showThemesStatus()`: Muestra estado de temas
  - Lista tema activo (obtenido desde WordPress)
  - Lista temas disponibles
  - Formato: "✓ Activo: [tema]" + "Disponibles: [lista]"

- `showPluginsStatus()`: Muestra estado de plugins
  - Lista plugins activos con orden numérico
  - Lista plugins inactivos
  - Formato: "✓ Activos (N): 1. plugin1, 2. plugin2" + "Inactivos: [lista]"

- `getActiveTheme()`: Obtiene tema activo desde WordPress
  - Ejecuta: `wp theme list --status=active --field=name`
  - Maneja errores silenciosamente

- `getActivePlugins()`: Obtiene plugins activos desde WordPress
  - Ejecuta: `wp plugin list --status=active --field=name`
  - Retorna array de nombres
  - Maneja errores silenciosamente

**Salida mejorada de `info`**:
