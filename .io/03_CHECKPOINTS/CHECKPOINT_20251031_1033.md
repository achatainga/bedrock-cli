- **Lenguaje**: PHP 8.0+

- **Patrón**: Command Pattern + Service Layer
- **Comandos**: 38 implementados

- **Stubs**: 14 plantillas para generación de proyectos

### Comandos Principales
1. **new** - Crear proyectos Bedrock con Docker/Acorn/Redis
2. **migrate** - Migración automatizada de BD (import + clean + search-replace)
3. **setup** - Instalación y configuración de WordPress
4. **acorn** - Menú completo de gestión de Acorn (11 opciones)
5. **plugins** - Gestión de plugins (10 comandos)
6. **themes** - Gestión de temas (5 comandos)
7. **options** - Exportar/importar opciones (5 comandos)
8. **docker** - Gestión de contenedores
9. **database** - Gestión de BD con seeders
10. **snapshot** - Backup/restore rápido
