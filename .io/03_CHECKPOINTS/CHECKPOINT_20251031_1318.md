## Arquitectura Final

### Flujo de uso simplificado:
```bash
# Instalación global (una vez)
composer global require achatainga/bedrock-cli:dev-develop

# Crear proyecto (sin bedrock-cli local)
bedrock new mi-proyecto --with-docker

# Usar comandos (desde instalación global)
cd mi-proyecto
bedrock setup
bedrock info
bedrock plugins:activate acorn

# Actualizar bedrock-cli
composer global update achatainga/bedrock-cli
```

### Comandos disponibles:
1. `info` - Estado completo (incluye temas/plugins)
2. `setup` - Setup completo (WP + Acorn + tema + plugins)
3. `docker` - Gestión de contenedores
4. `db` - Gestión de BD
5. `options` - Gestión de opciones WP
6. `plugins` - Gestión de plugins
7. `themes` - Gestión de temas
8. `acorn` - Gestión de Acorn
9. `backup` - Crear backup
10. `reinstall` - Reinstalar (DESTRUCTIVO)
11. `doctor` - Verificar dependencias
