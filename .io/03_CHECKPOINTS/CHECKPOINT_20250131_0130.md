## 🔍 ANÁLISIS TÉCNICO

### ¿Por qué SetupCommand falló?

**Hipótesis inicial (INCORRECTA)**:
- Pensamos que WP-CLI no respetaba `DB_PREFIX`
- Modificamos SetupCommand para usar prefijo manualmente

**Realidad (CORRECTA)**:
- `config/application.php` línea 103-105:
  ```php
  if (!isset($table_prefix)) {
      $table_prefix = env('DB_PREFIX') ?: 'wp_';
  }
  ```
- WP-CLI **SÍ lee** `config/application.php`
- WP-CLI **SÍ respeta** `$table_prefix`

**Causa real del problema**:
- Ambas tablas (`wp_users` y `hp2f_users`) existen
- WordPress puede estar confundido sobre cuál usar
- Necesita limpieza de BD (eliminar tablas `wp_*`)
